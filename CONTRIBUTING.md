# Contributing

1. Create a branch from `main`.
2. Install development dependencies with `python -m pip install -e ".[dev]"`.
3. Run `python -m pytest`, `python -m ruff check .`, and `python -m ruff format --check .`.
4. Keep hardware-specific claims tied to an OpenOCD configuration or a documented board test.
5. Submit a pull request describing behavior changes and test coverage.

Contributions are accepted under GPL-3.0-only.
